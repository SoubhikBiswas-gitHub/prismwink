# Implementation contracts

Root owns build scripts, manifest, distribution, integration tests, documentation and assets. Core worker owns effects.ts, gesture.ts, vision-worker.ts, vision-client.ts and core unit tests. Adapter worker owns hook.ts, content.ts, engine-frame.ts and background.ts. Studio worker owns studio.tsx and public studio/popup HTML/CSS. Do not edit another owner's files without coordination.

## Shared renderer

Export EffectRenderer from src/effects.ts. Constructor(canvas, { onState } = {}). Public setOptions({effect, duration, density, palette, reducedMotion, direction}), capturePlate(source), clearPlate(), toggle(source, mask, timestamp=performance.now()), render(source, mask, timestamp=performance.now()), recover(), destroy(). Getters state ('visible', 'vanishing', 'hidden', 'returning', 'recovery'), hasPlate, options. duration is milliseconds, density particle count; effect is dust/pixel/confetti/smoke. toggle returns false if transition, no plate, or no mask. Capture and toggle can throw descriptive errors. The renderer stores its plate in memory. A mask is {data:Uint8Array,width,height}, foreground alpha 0..255. onState(state) fires synchronously on transition start so the coordinator can gate audio immediately. render draws onto the supplied canvas. Hidden must never draw raw pixels. recover is an explicit user action returning to visible. Default 2500ms/4500 particles. Use 640x360 baseline.

## Vision

src/vision-client.ts exports VisionClient. Constructor({workerUrl}={}); defaults to extension-root vision-worker.js relative to document URL. async init(); async process(source,timestamp) -> {mask,gesture,handStatus}; process returns null if another inference is pending. handStatus is ready/pinched/no-hand. close() stops worker. Worker uses locally bundled tasks-vision and assets/wasm plus assets/selfie_segmenter_landscape.tflite and assets/hand_landmarker.task. No remote loading. Init timeout/failure must reject, never silently claim readiness. Close every transferred ImageBitmap. Keep tests independent of hardware when possible.

## Meeting bridge

Manifest injects hook.ts in MAIN at document_start and content.ts ISOLATED at document_start, only https://meet.google.com/*. Content builds a shadow dock and extension-origin iframe engine.html (script engine-frame.ts). Main hook renderer intercepts getUserMedia video, sends low-rate ImageBitmaps to iframe for vision, receives masks. At most one inference pending; raw video renders independently. Original audio tracks are retained for synchronous audio gating. Stop all raw camera resources when processed tracks stop. Preserve track constraints, audio-only capture, clones and device changes as far as feasible; report remaining limitations.

Content-to-hook window messages: {source:'prismwink-content',type:'config',engineUrl} then {source:'prismwink-content',type:'command',command,options}. Commands: capture, clear-plate, toggle, recover, configure, stop. Settings options follow renderer, plus gestures:boolean. Hook statuses: {source:'prismwink-hook',type:'status',state,hasPlate,visionReady,streamActive,micGated,handStatus,error,settings}. Hook mic requests: {source:'prismwink-hook',type:'mic',action:'mute'|'restore'}. Content responds with command 'mic-result', options {action,success,restoreAllowed}. Meet control synchronization is secondary to immediate track gating. Unknown state keeps mic muted. Content distinguishes user mic changes from its own clicks.

Iframe-to-parent: {source:'prismwink-engine',type:'ready'|'error'|'result',...}; parent-to-iframe {source:'prismwink-hook',type:'frame',bitmap,timestamp}. Verify event.source and exact origins both ways. Iframe result fields mask,gesture,handStatus; transfer mask.data.buffer. The content-owned iframe id is prismwink-engine. Worker lives entirely in extension origin for Wasm content-policy compatibility. The hook must know iframe is ready before sending frames. Config is sent after the iframe is appended. Native gUM remains responsive during vision loading; effect controls disabled until ready. Camera setup failure rejects the failed capture and stops its tracks; no untracked raw fallback is returned. Hidden recovery must cover every active camera session.

## Studio

Root studio.html and popup.html load the React entrypoints src/studio.tsx and src/popup.tsx through Vite. Studio uses renderer + VisionClient directly. Permission-free illustrative sample is explicitly labeled Demo; camera mode asks permission only on user action. Camera and microphone controls, empty-room capture/countdown, manual toggle, visual gesture practice, settings, favorites and saved presets may be implemented. Experimental items must not be advertised as supported. Core launch first, feature expansion later. Root supplies sample-room.svg and sample-person.svg in public/assets. Fonts at assets/fonts/bricolage.ttf and manrope.ttf. Shared icon at assets/icon.svg, PNG sizes in assets/icons/icon-{16,32,48,128}.png. Settings in chrome.storage.local if available, localStorage on localhost for preview. Use literal textContent for imported text and validate schema. No inline scripts in extension pages.

User requires TypeScript throughout source and React with react-dom/client for studio/popup UI. Bundle output remains .js and public HTML must reference .js files, not .ts. Strict typecheck is a release gate.

The renderer exposes `quality` as full/balanced/light. It measures transition rendering cost and reduces particle drawing after sustained slow frames, recovering gradually; the selected preset remains unchanged. Display any automatic reduction explicitly.
